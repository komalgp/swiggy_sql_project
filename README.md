# swiggy_sql_project
The "Swiggy Advanced SQL Project" analyzes Swiggy's database using advanced SQL queries to extract insights on customer behavior, restaurant performance, delivery partner efficiency, and order trends.It includes operations like calculating average ratings, revenue, order patterns, and delivery metrics, showcasing real-world SQL applications.
# Swiggy SQL Data Analysis Project
## Project Overview

This project is an Advanced SQL Data Analysis project based on Swiggy, India’s leading online food delivery platform.
The objective of this project is to analyze customer behavior, restaurant performance, order trends, and delivery partner efficiency using SQL queries on a relational database.

The project simulates real-world business scenarios and answers key analytical questions that are commonly asked in Data Analyst interviews and real industry use cases.

# About Swiggy

Swiggy, founded in India in 2014, is a popular on-demand food delivery platform that connects customers with restaurants and delivery partners. Over time, Swiggy has expanded into grocery and instant delivery services, continuously evolving in a highly competitive market.

# Key SQL Queries & Business Questions Solved
##  Customer Analysis

Display all customers who live in Delhi

List all customers who have placed at least one order

Display all customers who have never placed an order

Display the total number of orders placed by each customer

Find customers who placed orders on exactly three different days

Identify customers from the same city who ordered from the same restaurant on different dates

## Restaurant Analysis

Find the average rating of restaurants in Mumbai

Find the total revenue generated by each restaurant

List the top 5 restaurants with the highest average rating

## Order Analysis

Display all orders placed in the last 30 days

Find the number of orders placed by each customer in Mumbai

## Delivery Partner Analysis

List all delivery partners who have completed more than one delivery

Find the delivery partner who has worked with the maximum number of different customers
